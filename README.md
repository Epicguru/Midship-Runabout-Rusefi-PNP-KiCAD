Very quick brief readme for what has been dumped in here.

This is MRRusEfi aka RusEFi UAEfi PnP Pcb for the 1zz / 2zz MR2 ZZW30 - as found on the ThreepotMR2 Youtube channel.

You will find:-

MRRpinout.png = How to wire stuff into the magic 5th Connector including wideband pinout.
Schematic_PnP-ECU2-Rev2_2026-10-17.png = Schematic for the whole MRR PCB.

BeanBanger_CAN_ESP32.zip = Arduino Project for the ESP32 Bean Banger with working AC support
UADash_code.zip = Source code for the UADash with the AFR/Lambda Gauge and Boost Gauge
UADash_Firmware.zip = Source Code Compiled to upload to your waveshare ESP32 monitor

new pnp board.zip = Tunerstudio backup of the project fully working with a 1zz turbo tune running Subaru Injectors
